# Beta House - Minecraft Beta 1.7.3 Custom Map

A custom-built map named "Beta House" designed for **Minecraft Beta 1.7.3**, created using mods for world generation and creative features, and released under the **CC0 1.0 Universal** public domain dedication.

## Map Overview

* **Map Name:** Beta House
* **Game Edition:** Minecraft Java Edition
* **Game Version:** Beta 1.7.3
* **Map Type:** Custom Build / Flat World
* **License:** CC0 1.0 Universal (Public Domain)

## Important Compatibility & Prerequisites

Because this custom map was created for Minecraft Beta 1.7.3 (an era before flat world generation and creative mode existed natively), **you must install the Babric modloader and the required mods** for the map to load and function properly.

### Required Modloader
* **Babric Installer:** [Download Babric Installer](https://babric.github.io/use/installer/) *(Supports both the Vanilla Launcher and Prism Launcher/MultiMC)*

### Required Mods (Modrinth)
You need to place the following `.jar` mods into your instance's `mods` folder along with Babric:
1. [BH Creative](https://modrinth.com/mod/bh-creative)
2. [StationAPI](https://modrinth.com/mod/stationapi)
3. [Better World Options](https://modrinth.com/mod/better-world-options)
4. [Glass Config API](https://modrinth.com/mod/glass-config-api)
5. [Glass Networking](https://modrinth.com/mod/glass-networking)

## Installation Instructions

### 1. Installing Babric and Mods

#### Via Prism Launcher / MultiMC:
1. Open Prism Launcher and create a new instance for **Minecraft Beta 1.7.3**.
2. Edit the instance, click on **Install Loader**, and select **Babric**.
3. Download the required `.jar` mods listed above.
4. Go to the **Loader Mods** tab in Prism Launcher and add the downloaded mod files.

#### Via the Official Minecraft Launcher:
1. Download and run the [Babric Installer](https://babric.github.io/use/installer/).
2. Select Minecraft Beta 1.7.3 and install the Babric profile.
3. Open your `.minecraft` folder, locate or create the `mods` folder inside your Babric profile directory, and place all the required `.jar` mods there.

---

### 2. Installing the Map ("Beta House")

Once your Babric environment and mods are properly installed:

1. Download the `Beta House` map folder.
2. Open your Minecraft saves directory:
   * **Windows:** Press `Win + R`, type `%appdata%\.minecraft\saves` (or look inside your Prism Launcher instance folder under `.minecraft/saves`), and press Enter.
   * **Linux:** Navigate to `~/.minecraft/saves` or your Prism instance saves folder. *(Tip: Press `Ctrl + H` to reveal hidden folders).*
   * **macOS:** Open Finder, press `Cmd + Shift + G`, and type `~/Library/Application Support/minecraft/saves`.
3. Paste the `Beta House` folder directly into the `saves` directory.
4. Launch your Minecraft Beta 1.7.3 Babric profile, open Singleplayer, and select **Beta House**.
