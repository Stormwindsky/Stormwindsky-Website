## Installing the Map ("WillieBoat House")

Once your Better Than Adventure! launcher and environment are properly set up:

1. Download the `WillieBoat House` map folder.
2. Open your BTA saves/worlds directory:
   * **Windows / Prism / MultiMC:** Locate your BTA instance folder, navigate to `.minecraft` or the game directory, and open the `saves` (or `worlds`) folder.
3. Paste the `WillieBoat House` folder directly into that directory.
4. Launch Better Than Adventure!, open Singleplayer, and select **WillieBoat House** to start playing!
